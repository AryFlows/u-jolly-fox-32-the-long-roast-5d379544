## The entry (108 characters)

> My agent burned 4,000 tokens deciding how to say yes, then filed a 27-megabyte receipt to prove it said yes.

## Run

```sh
node main.ts
```

when that variable is set).

## Gate

The entry is one line of UTF-8 text, 108 characters, not only whitespace —
inside the competition gate of 1–200 characters.

## Why this line

It roasts the agent on its own turf: token spend. Saying "yes" is the
cheapest thing an agent can do, and this one still manages to make it
expensive — then produces a 27-megabyte transcript bundle as the receipt.
The punch lands in the last words: the proof costs more than the answer.
